1. Seller submissions awaiting approval

Paste the seller form submission exactly as the form dashboard gives it to you — nothing to reformat. Each submission is only a proposal: nothing is public until you approve and publish it.

What can I paste?
  • Field name, then its value on the next line — copying a submission card usually gives this. Paste it as it comes.
  • Field: value — one per line, e.g. Business: Rose Cafe.
  • A pasted table — select the values in the dashboard and copy; tabs are handled.
  • JSON — a single object or an array of them; data, fields and values wrappers are unwrapped.

Submissions live at this form's dashboard. Uploaded documents are linked there, with links that expire after 7 days — download them when you review.

Sign in to publish listings

Publishing writes to your GitHub repository, so the dashboard signs in with a GitHub fine-grained personal access token instead of a password. Create one for this repository only, with Contents: Read and write permission.

  1. Open GitHub → Settings → Developer settings → Fine-grained tokens.
  2. Generate new token: name it Third Wave website, set an expiry, and under Repository access choose Only select repositories → florasafaris2020-lang/third-wave-solutions.
  3. Under Permissions → Repository permissions set Contents to Read and write. Nothing else is needed.
  4. Generate, copy the token, and paste it below. It stays in this browser and is never sent anywhere except GitHub.
